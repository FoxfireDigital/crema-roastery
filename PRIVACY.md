# Privacy and data ownership

This source release contains no customer records, staff hours/pay rates, orders, balances, credentials, uploaded labels, photos, roast profiles, machine serial information or original Git history. Catalog/profile seed data and private historical migrations were replaced with an empty schema and fictional opt-in examples.

Each operator controls their instance’s database, accounts and retention. Imports, labels, photos, supplier contacts, tasting notes, timesheets and audit history are private business data. Exports and full backups must be protected accordingly. Soft removal retains history; it is not a legal-erasure function. A hosting operator must define access, retention, deletion and export procedures for their customers.

No telemetry or central cloud login is included. Shopify makes authorized requests only when configured. Optional external bookmarks open separate services. The camera is optional and requests browser permission; uploaded images can contain original metadata, so review sharing policies before publishing photos.

The release privacy scanner checks known private markers, credential patterns, unsafe file types and nonempty bundled catalogs. It is a release gate, not a guarantee that arbitrary future contributions contain no confidential data. Review every release and its generated archive.
