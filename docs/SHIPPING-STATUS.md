# Shipping labels and production confirmation

Marketplace fulfillment status and actual coffee production are separate facts. An early shipping label can mark an order fulfilled while roasting or packing remains unfinished. Crema retains imported demand and actual results, but puts source changes on hold for review.

For an unchanged paid order **already on an active plan**, open Imports or Plans and choose **Confirm still needs production**. Review its saved demand, record the reason, confirm remaining work, and save. Review and accept the existing plan to continue. Do not remove/re-import an order to work around its shipping status.

The confirmation is audited and applies to the current source information and plan assignment. Identical refreshes preserve it. Item/quantity, payment, cancellation, instruction or assignment changes invalidate it; an old approval does not return automatically if source values revert. The source's fulfillment status stays unchanged. Existing measured/roasted weights, stock use and packing remain unchanged, and the order cannot be imported a second time.

This exception cannot override cancelled/unpaid orders, changed items, source flags, partial deliveries or closed/historical plans. An already fulfilled order that was never imported still needs separate quantity/source review; this control does not add it automatically. Shipping status alone never marks coffee roasted or closes a production plan.

Where practical, finish production and packing before creating shipping labels. The confirmation handles exceptions; it is not a replacement for actual finished weights or packing checks.
