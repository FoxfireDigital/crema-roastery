# Optional green-stock review and origin substitutions

On a roast plan, the Green stock card offers **Check recorded green stock** or **Skip stock check**. Skipping is recorded as availability not checked, never as a successful count. Planning, acceptance and roast recording do not require this advisory check. Manual counts remain the operator's responsibility. Configured recipes still deduct actual green input when a batch is Measured, even when the advisory check is skipped.

Without green origins and recipes, the card identifies the missing setup and lets you continue manually. Add origins, actual counts and blend percentages when ready; do not invent an opening balance. A recorded-balance check is not a physical count or a green-stock reservation.

In each origin's supplier/details screen, optionally record known suitable roast levels, comma-separated flavor tags and caffeine type. Shortage suggestions rank documented roast suitability for the planned roast first; shared flavor tags break ties at the same roast distance. Undocumented information stays unknown. Known decaf/caffeinated mismatches and alternatives that cannot cover the plan's recorded requirement are excluded. This is a transparent rule-based suggestion, not a claim that two origins taste equivalent.

Choose **Request substitution**, then review the request before approval. Verify roast suitability, caffeine type and product/label suitability. For an origin-named product, review customer expectations and artwork before approving a different origin. A request alone changes no ingredients or inventory. No email or external notification is sent.

Approval replaces that ingredient in the frozen recipe for the plan group's unmeasured loads, preserving its percentage and merging it if the replacement is already another ingredient. It leaves the ordered coffee, packaging and global recipe unchanged. Beans are deducted only when Measured. Already measured batches keep their original frozen ingredient records. Approval is not a green-stock reservation; recheck actual counts as work proceeds.

Changes in stock or the plan invalidate an old request. Decline it and make a current request. Approval/cancellation changes the plan revision, so refresh open production screens and download a fresh Artisan preparation. The reference curve is not automatically converted to a different origin.

**Cancel substitution for remaining loads** returns future loads to the global recipe; it does not rewrite measured history or return beans from an actual roast. Origin labels and flavor notes can be improved over time; missing notes never prevent using Skip stock check.
