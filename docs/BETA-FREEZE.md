# Beta scope freeze and maintainer review

The feature baseline is 0.1.0-rc12, source revision a7e7c5a32aa4b570302d615de2f11b5e6f7a81ea. The corrective candidate is 0.1.0-rc13. Existing order-to-plan, stock, roast/cooling, packing/labels and supporting workflows are frozen. New feature work waits until the beta review is complete. Only verified defects, distribution/security corrections, essential documentation and relevant tests belong in this candidate.

The maintainer review compared the baseline archive with its manifest and committed source, scanned all thirteen reachable commits and their identities, exercised103 anonymous route boundaries, checked privileged recovery and employee record access, rejected invalid uploads and writes, verified signed/replayed notifications, and inspected an actual generic image. The isolated PostgreSQL, HTTPS, restart and consistent database/key restore trial passed. These are bounded maintainer checks, not a completed independent assessment.

Corrections in rc13: escape formula-like employee names in the legacy time export; label payroll times using the configured timezone; reject non-finite custom weights and malformed machine identifiers without creating production; remove the build-only package installer, its vendored libraries and bootstrap wheel from the runtime filesystem. The image verifier checks that installer removal. Base and service references are frozen by digest for repeatable review. Source-build instructions remain the candidate installation route; no public registry artifact is advertised.

Broader container scanning identified operating-system, vendored installer and supporting-image advisory matches not covered by the installed-Python audit. Removing the installer addresses that unnecessary runtime bundle. Do not describe all scanner matches as exploitable, or all remaining matches as cleared. Exact-image findings, affected-code/reachability evidence and qualified disposition must accompany publication review. Available notice files and upstream component manifests do not establish every source-distribution obligation by themselves.

Remaining gates: independent security review and disposition of relevant advisories; complete dependency/native-library/source distribution review; documented operator and small external pilot; approved public generic image and anonymous deployment test; final source/image visibility approval. Marketplace integrations without merchant-account trials remain experimental. Paid hosting has separate service and isolation gates. The source, drafts and images remain private throughout this review.
