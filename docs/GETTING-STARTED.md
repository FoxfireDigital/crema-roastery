# Guided roastery setup

Staff open **More → Getting started**. The checklist is available again whenever configuration changes. It never changes settings, orders, stock, accounts or production, and there is no “mark everything complete” control.

Start with the three core checks: name/preferences, machine limits and active coffees/roast rules. The progress indicator describes those saved inputs only. **Configured** means the listed configuration is present and passes the displayed checks. It is not a safety approval or proof of a complete production setup. A machine with a zero/unset minimum is called out for review.

Then review the supporting steps:

1. Green origins, recipes totaling 100% and fresh bulk roasted counts. Inactive bagged/on-deck lots do not make a usable recipe. This is optional for planning, but automatic green tracking needs a usable recipe or a deliberately chosen direct origin.
2. One or more marketplaces, or explicit manual/CSV-only use. Saved connections are distinct from successful refreshes; no request to a marketplace is made just by opening the checklist. New marketplace adapters retain their experimental status.
3. Artwork and plain-paper alignment. The checklist detects coffees with no available art, including installation-supplied catalogs. The artwork matrix still determines size, roast, special-label and layout coverage.
4. Cost profiles. Missing inputs stay unknown. Reviewed input completeness does not certify actual prices or coverage of every product size.
5. Artisan references and optional Companion pairing. Unexpired pairing does not prove the computer is online or that Artisan and alarms work. Test while idle; never automate roaster operation.
6. Individual accounts and access. Staff and pay-manager authority are separate. Counts do not prove permissions are appropriate.
7. A consistent database backup with matching instance keys, a separate restore and an end-to-end first-day rehearsal. External backup and physical tests always remain **Review in person**.

Each card links to the existing editing or review screen. Return to the checklist after saving; it recalculates automatically. Permission-restricted settings are offered only to users with the corresponding permission. The public shared demo provides a fictional, read-only checklist preview while installation settings, live connections, account administration and recovery remain blocked. Ordinary employees cannot access the setup checklist.

Use a separate practice installation for fictional orders. Do not populate real production history with demonstration work. No optional setup item blocks an otherwise valid production workflow.
