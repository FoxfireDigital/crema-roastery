# Artisan preparation and review

Create a preparation from an accepted, unroasted load. Choose the approved profile and First for a cold machine or one idle for ten minutes; choose Second for continuing warm roasts. Confirm the machine, green weight and targets. Extract the full downloaded ZIP on the Windows roasting computer and run Prepare-Artisan.cmd while Artisan is idle and previous work is saved.

The generated title is **Coffee name 40.0oz 1 FC**: scheduled green input in ounces to tenths, First=1 or Second=2, followed by City=C, City+=C+, Full City=FC, Full City+=FC+, Vienna=V or French=F. Reference curves, weights and events are preserved; only the prepared copy's title and alarm fields change. Stored originals remain unchanged.

Artisan 3.1's existing-instance background connection sets the background title, not the active roast's Title. The helper offers to copy the generated title to the Windows clipboard, replacing its current text only if accepted. Open **Roast → Properties**, paste into **Title**, and confirm. A copy button and roast-title.txt provide alternatives. No blind keystrokes or hardware-control commands are used. Artisan retains its autosave settings; include its date/time or batch counter in filenames if repeated titles could otherwise collide.

After the physical roast, save the completed **foreground .alog** in Artisan. Mark the corresponding Crema batch Roasted (or record its finished weight). On Today, choose **Upload finished roast**, or reopen its preparation page. Preview the file, select the reference deliberately, review the date and curve, then confirm and attach. The review page shows the curve, comparison and notes and retains an unchanged download of the original file. Attaching a log does not overwrite measurements, status or inventory. Uploads are manual; a watched-folder uploader is not included.

The helper loads backgrounds and alarms only. It does not start monitoring, recording, heating or roasting. Check the targets and correct USB machine in Artisan before operating it.
