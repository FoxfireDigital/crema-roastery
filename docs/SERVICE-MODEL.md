# A practical hosted-service offering

Keep the software free under MIT and sell work that helps a roastery use it successfully:

- Initial catalog, machine, recipe and artwork setup.
- Rehearsed imports and migration from existing records.
- A separate managed installation, database and secret set for each customer.
- Encrypted offsite backups, scheduled restore rehearsals, monitoring and updates.
- Training, workflow configuration and ongoing support.

Operators should retain access to their own data exports and recovery documentation. Explain hosting and support charges separately from the software license. MIT permits customers to self-host or choose another provider; the service should earn its value through dependable operation and support.

Start with a small pilot. Measure setup time, support requests, failed imports, recovery time and actual hosting costs before setting prices. Agree on data ownership, staff access, retention, backup objectives and response expectations. Shared tenancy, automated billing, payroll compliance and automatic hardware operation require separate work and should not be promised by this candidate.
