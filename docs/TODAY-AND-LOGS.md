# Today and completed roast logs

Today records Measured → Roasted → Cooled. Cooling is explicitly confirmed by the operator, never inferred from a finished weight, an uploaded log or an old packing timestamp. Existing batches start with cooling unrecorded. Entering a positive finished weight continues to mark Roasted automatically; Roasted can also be checked before weighing. Corrections use existing stale-save and audit/undo protection. The Hide cooled view hides completed roasting work only.

Bagging, grinding, flavoring, labeling and sealing stay on the customer packing checklist. Today does not set or clear legacy batch bagging/sealing timestamps or order-line packing progress. Cooling does not add a new packing or plan-closure gate to existing work.

On Today, Review roast / logs opens the batch's Completed Artisan logs section. Each attachment shows the actual bean-temperature curve aligned at Charge with its frozen reference, if one was selected. Logs are paged five at a time. Missing or unverifiable references warn and show only the verified actual curve; an unverifiable actual file warns instead of drawing a misleading curve. The original download and full notes remain available. These previews remain staff-only and never alter production, stock, file bytes or reference choices.

The More menu groups Coffee & artwork above Connections & orders in the same column; mobile reading order keeps those groups together.
