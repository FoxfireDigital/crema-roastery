How the Artisan connection works

On Today choose Prepare in Artisan beside an unroasted load. Select an approved profile and download its preparation folder. On the Windows roasting computer, extract the folder and run Prepare-Artisan.cmd.

The helper reuses Artisan’s existing main window. If Artisan is closed, it asks you to locate artisan.exe and opens it. If an existing process cannot be reached, it stops instead of opening another copy. Confirm idle state and the connected machine; Artisan does not expose a load acknowledgement through this connection, so you verify the loaded curve and alarm table.

It does not start monitoring, recording or a roast, alter production results, or upload completed curves. The first real-machine connection test remains to be done at the roastery. Off means Artisan monitoring OFF; configured machine actions depend on that computer’s Artisan settings.
