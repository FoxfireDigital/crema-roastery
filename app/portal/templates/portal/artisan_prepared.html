On the roasting computer

  1. Extract the downloaded ZIP to a local folder; keep all its files together.
  2. Run Prepare-Artisan.cmd. It checks file integrity and confirms your load.
  3. If Artisan is open, the helper uses its main window. If closed, choose artisan.exe to open it. An unreachable existing process stops preparation.
  4. Confirm Artisan is idle, monitoring is OFF, earlier work is saved and the correct machine is connected.
  5. Verify the background curve loaded, then allow the paired alarm request. Check Config → Alarms for the three targets.

Enable Load from background for embedded alarms. The helper sends no ON, START or roast-control commands. Off is Artisan’s monitoring action. Start and run the physical roast yourself, then record actual finished weight in the portal.

This helper targets Artisan 3.1.0 on Windows. First live-machine validation is still required. Downloads contain no login credentials. If anything changes after download, discard the old folder and prepare again.
