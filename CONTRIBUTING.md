# Contributing

Keep changes small, document user-visible behavior and add meaningful regression coverage for state transitions and inventory. Do not commit .env, state/, databases, backups, customer fixtures or third-party artwork/profiles. Use synthetic examples only.

Run the Django tests and release privacy scanner before proposing a change. Preserve immutable originals and audit records. Never turn reservations into fabricated production output. New integrations should have explicit permissions, bounded parsing and safe retries.

Contributions are under this project’s MIT license. Third-party code/assets require compatible licenses and attribution; a screenshot or uploaded file does not grant redistribution rights.
